## Design and craft

Sprite craft, character construction, concept art, art consistency, and game visuals converge on silhouette → large material/value masses → directional shading → edge decisions → sparse detail. Establish numeric body height, joint landmarks, visual scale, pivot, ground baseline, and camera context from the real scene. Transparent canvas space is not body size. Expand attack gutters around a fixed anchor; never shrink each pose to fit. Account for both limbs and intentional occlusion. Preserve joint attachment, volume, and thickness through foreshortening.

After audit/research, write a new whole-body law specifying initiator, delays, center of mass, shoulders/ribcage/pelvis, uneven arm/leg rhythm, release, overshoot, and recovery. Explore alternatives, reject generic moving silhouettes, and prove it in eight masters before expansion. With FLAME hidden, BODY must retain identity; restored FLAME must convey distorted self-image. A striking head cannot rescue generic locomotion.

Reality uses muted charcoal, dirty gray, brown-gray, faded olive, worn beige, dull skin, restrained blue-gray. Perception alone uses blood red, vermilion, orange, pale hot peach, black void. Assign exact hex/material/value roles. Broad quiet regions, shared shadows where useful, selective detail, no wallpaper folds, random distress, dithering, glow, or reflected fire. Black void is not a universal outline.

Production raster is authored at native resolution and created/edited INSIDE Pixelorama through MCP explicit pixel batches. No Python/PIL drawing, procedural geometric character, rigid cutout puppeting, generated/downsampled base, automatic shading, or noise. The MCP playbook supplies batching/transport only; its geometry recipes are excluded. Separate BODY, FLAME, WEAPON, optional FX. Document the same anatomical grip hand and root/tip anchors through mirroring.

Pose-to-pose keys, purposeful asymmetric spacing, holds and fast crossings must fit existing state timing. Contact/down/passing/high poses retain limb ownership; do not mirror a half-cycle and silently swap hands. Judge three full loops and transitions. No interpolation, arbitrary rotation/scaling, or blend-generated pixels. Redraw compression while preserving believable mass. Flame secondary emotional anatomy: contained idle, backward run lag, delayed rise stretch, upward fall drag, severe dash deformation, antic compression, contact tear/shear, recovery snap, hurt fragmentation, death loss of structure. No eyes/skull/hero hair/aura/magic/particles.

## Integration and evidence

Simulation drives presentation in one direction. Preserve input, movement, physics, Blink, damage, hitboxes, buffering, cancels, action timings. Contact artwork matches existing damage windows; do not transfer damage into animation events. Use the smallest existing visual hook and current architecture; no new gameplay state machine/camera/global render tuning.

Every animation gets TWO real MCP correction passes with before/after evidence and concrete pixel edits. Pass 1: anatomy, proportions, ground contact, silhouette, center of mass, pivot, arcs. Pass 2: clusters, tangents, orphans, palette, flame phase, native-scale readability. Return to Pixelorama for runtime faults. Statistics support visual judgment, never prove identity/motion.

QA: alpha only 0/255, palette, duplicates versus purposeful holds, edge clearance, dimensions/pivot, paired anatomy, anchors, baseline, arcs, seams, body-only read. Inspect 1x and integer enlargement against actual environment and contrasting backgrounds. Python/PIL may analyze/package existing exports only. Lossless PNG, local nearest, no unwanted mipmaps, stable offsets, .pxo source, modular exports, metadata, safe rollback. Retain legacy art; avoid mutating shared resources accidentally.

Validate import/parse and relevant existing regressions, graphical gameplay, real input, both facings, cycles/transitions for actual states. Save logs/captures. Source, headless, graphical, input-replay, exported-build evidence are distinct; never claim an unperformed level.
